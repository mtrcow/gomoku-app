## 1. 核心功能

### 1.1 棋盤渲染

- **棋盤尺寸：** 15 × 15 格，標準五子棋規格
- **響應式設計：** 棋盤佔螢幕寬度 90%，自動適配各種設備
- **星位標記：** 天元及四角星位以小圓點標示，方便定位
- **最後落子高亮：** 最後一手棋子外圈顯示紅色標記，一目了然
- **支援觸控 / 滑鼠點擊落子**

### 1.2 落子邏輯

- **黑白交替：** 黑棋先行，嚴格交替落子
- **非法位置防護：** 已存在棋子的位置、棋盤外區域不可點擊
- **動畫效果：** 棋子帶有輕微下落動畫，增加視覺反饋

### 1.3 勝利判定

滿足以下任一條件即獲勝：

| 連線類型 | 說明 |
|----------|------|
| 橫向連線 | 水平方向連續五子 |
| 直向連線 | 垂直方向連續五子 |
| 左斜連線 | 左上至右下方向連續五子 |
| 右斜連線 | 右上至左下方向連續五子 |

> ⚠️ **長連不勝：** 若連成六子或以上，仍只算勝一局，不重複計算。

### 1.4 雙人對戰

- 兩位玩家共用同一設備，輪流操控
- 黑棋、白棋分別代表玩家一、二
- 適合與家人、朋友面對面對弈

### 1.5 悔棋功能

| 模式 | 悔棋行為 |
|------|----------|
| **人機對戰** | 撤銷最近兩步（同時撤銷玩家的悔棋回合和AI的回應） |
| **雙人對戰** | 撤銷最近一步（當前輪玩家的上一步） |

- 悔棋次數**不限**
- 遊戲開始後任何時間皆可悔棋
- 結算頁、開始頁不可悔棋

### 1.6 重新開始

- 一鍵清除棋盤，恢復初始狀態
- **保留設定：** AI難度、計時模式開關等設定維持不變
- **清除狀態：** 歷史記錄、計時歸零、勝者重置

### 1.7 認輸

- 玩家可隨時點擊「認輸」按鈕提前結束對局
- 對手直接獲勝，進入結算頁
- 計入對戰統計（認輸記為負）

### 1.8 對戰統計

記錄以下數據：

- **總場次** — 歷史總對局數
- **勝利** — 累計獲勝次數
- **失敗** — 累計失敗次數（含認輸）
- **和局** — 棋盤下滿且无人获胜的局數

> 📊 統計數據目前存於本地，未來版本支援雲端同步。

### 1.9 音效系統

| 音效 | 觸發時機 |
|------|----------|
| 落子聲 | 每次成功落子 |
| 勝利音效 | 玩家獲勝 |
| 失敗音效 | 玩家落敗 |
| 計時警示音 | 倒數最後 5 秒，每秒嗶一聲 |

- 音效可在設置頁一鍵關閉

## 2. 人機對戰 AI 難度

### 2.1 算法基礎

AI 使用 **Minimax 演算法** 配合 **Alpha-Beta Pruning（α-β 剪枝）** 進行搜索，確保在合理時間內給出最佳落子決策。

### 2.2 三種難度詳解

#### 🟢 簡單（Easy）

- **搜索深度：** 2 層
- **評估函數：** 基礎啟發式（計算當前棋子威脅）
- **響應速度：** < 1 秒
- **適合對象：** 初次接觸五子棋的新手，或純休閒放鬆的玩家
- **AI 特色：** 偶爾會出現「新手失誤」，不會刻意防守

#### 🟡 中等（Medium）

- **搜索深度：** 4 層
- **評估函數：** 優化啟發式（同時計算攻守形勢）
- **響應速度：** 1–3 秒
- **適合對象：** 有一定五子棋基礎，想要練習策略的玩家
- **AI 特色：** 會進行基本防守，會識別簡單的連衝/連活

#### 🔴 困難（Hard）

- **搜索深度：** 6 層
- **評估函數：** 高級啟發式（引入位置權重 + 棋型識別）
- **響應速度：** 3–8 秒（複雜局面可能更長）
- **適合對象：** 自信有一定棋力，想挑戰自我的高手
- **AI 特色：** 攻防兼備，會主動進攻，防守嚴密，難以找到破綻

### 2.3 AI 落子響應流程

```
玩家落子 → 評估局面 → Minimax搜索 → Alpha-Beta剪枝 → 選擇最佳落子 → AI響應
```

## 3. 計時模式規則

### 3.1 規則說明

- **計時時長：** 每手 **30 秒**
- **適用模式：** 人機對戰、雙人對戰（可選開關）
- **超時處理：** 超時方直接判負，對手獲勝

### 3.2 計時器顯示

| 剩餘時間 | 顯示顏色 | 狀態 |
|----------|----------|------|
| > 10 秒 | 白色 | 正常 |
| 6–10 秒 | 黃色 | 注意 |
| 1–5 秒 | 紅色 + 閃爍 | 警示 |
| 0 秒 | 紅色靜止 | 超時 |

### 3.3 特殊規則

- **暫停：** 計時模式下不可主動暫停
- **悔棋：** 悔棋後計時器**重置**為 30 秒
- **重新開始：** 計時器歸零重新開始
- **和局：** 棋盤下滿仍未分勝負 → 和局（計時不影響）

## 4. 操作說明

### 4.1 開始遊戲

1. 從**開始頁**選擇對戰模式：
   - 點擊 **「人機對戰」** → 選擇 AI 難度 → 進入遊戲
   - 點擊 **「雙人對戰」** → 直接進入遊戲
2. （可選）開啟**計時模式**開關

### 4.2 落子

- **操作：** 點擊棋盤上任意空格交叉點
- **確認：** 放開後視為確認落子
- **動畫：** 棋子帶有 200ms 下落動畫

### 4.3 悔棋

1. 遊戲中點擊 **「悔棋」** 按鈕
2. 人機模式：等待AI撤銷（約1秒）
3. 雙人模式：直接撤銷上一步
4. 棋盤恢復到上一次落子前的狀態

### 4.4 重新開始

1. 遊戲中點擊 **「重新開始」** 按鈕
2. 彈出確認對話框，點擊「確認」
3. 棋盤清空，計時器歸零，黑棋先行

### 4.5 認輸

1. 遊戲中點擊 **「認輸」** 按鈕
2. 彈出確認對話框
3. 確認後直接跳轉至結算頁，對手獲勝

### 4.6 結算頁操作

| 按鈕 | 行為 |
|------|------|
| **再來一局** | 以相同設定重新開始 |
| **返回主頁** | 回到開始頁 |

## 5. 遊戲狀態說明

### 5.1 棋盤狀態值

```
0 = 空位
1 = 黑棋（玩家1 / 人機模式玩家）
2 = 白棋（玩家2 / 人機模式AI）
```

### 5.2 遊戲進程狀態

```
等待開始 → 遊戲中 → （勝/負/和/認輸） → 結算頁
```

### 5.3 按鈕狀態一覽

| 按鈕 | Default | Disabled |
|------|---------|----------|
| 悔棋 | 可用 | 遊戲未開始、結算頁 |
| 重新開始 | 可用 | 無 |
| 認輸 | 可用 | 遊戲未開始、結算頁 |
| 落子 | 可用 | 非空位、遊戲未開始、輪到AI時 |
